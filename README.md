# iFix - protótipo com cadastro

Protótipo estático em HTML, CSS e JavaScript. Inclui login local, cadastro separado de cliente e prestador, bloqueio da área principal até a entrada e layout baseado na identidade azul e amarela da logo.

## Publicar no GitHub Pages
Envie a estrutura preservando as pastas `css`, `js` e `images`. Em Settings > Pages escolha `Deploy from a branch`, branch `main`, pasta `/(root)`.

## Importante
Os cadastros ficam apenas no `localStorage` do navegador. Não há servidor, criptografia, validação de documentos ou autenticação real. Use apenas dados fictícios.
